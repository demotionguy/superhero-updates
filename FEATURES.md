# Superhero — aage jud sakne wale features

> **PEHLE PRIORITY (sabse upar, pakka):** Pehle maujooda changes pure honge —
> (1) Dimaag ka ek-click setup taaki "dimaag so raha hai" wala sandesh hamesha ke liye khatm ho,
> (2) naya premium UI (3D orb, motion, glass chat, dark mode).
> Neeche wale features uske BAAD, ek-ek karke, Hy ke kehne par judeinge.

## Pakke niyam (har feature inke andar hi rahega)
- Koi file **bina Hy ki ijazat nahi khulegi** — program khud ijazat maangega, sirf wahi file jo Hy ne khud boli ho.
- **Badi file kabhi swallow nahi** hogi — sirf uska path + 2–4 line ka summary yaad rahega.
- Sab kuch **offline aur free (₹0)** — koi paid service, koi token, koi company API nahi.
- Memory **sirf shabdon (words) me** rahegi — chhoti, halki, hamesha wali.

## Aage ke features (har ek, ek line me)
1. **Voice se baat** — Hy bolkar likh sakega aur Superhero ka jawab bolkar sun sakega (laptop ke apne offline tools se).
2. **Yaad ki khoj (memory search)** — "maine tumhe woh wali baat kab batayi thi?" poochhne par purani yaadon me se dhoondh kar jawab.
3. **Seekhe kaam ki list + ek-tap dohrana** — saare seekhe hue kaam ek list me dikhenge, ek dabane par wahi kaam dobara ho jayega.
4. **Reminder** — Hy bole to Superhero samay par yaad dilayega ("kal 10 baje yaad dilana"), sab laptop ke andar hi.
5. **Ijazat se file ka summary** — Hy jis file ki ijazat de, Superhero sirf usi ka 2–4 line summary banakar yaad rakhega (poori file kabhi nahi).
6. **Roz ka diary page** — har roz ki baatein aur notes ek saaf diary page me, tareekh ke hisaab se.
7. **Password lock** — app khulne par Hy ka apna password, taaki koi aur laptop chhue to bhi Superhero band rahe.
8. **Memory backup / restore file** — ek click par saari yaadon ki ek chhoti backup file, aur zaroorat par wahi wapas (restore).
9. **Theme badalna** — halka (cream) / gehra (dark) rang aur apni pasand ka accent, ek dabane par.
10. **Subah ki report** — app khulte hi chhoti si report: aaj ke reminder, kal ki diary, aur pending seekhe kaam.

---
*Note: Ye sirf sujhaav ki list hai. Koi bhi feature Hy ke bole bina nahi banega, aur paisa lagne wala koi kadam pehle Hy ko bataye bina kabhi nahi hoga.*
