# Superhero — STORAGE SEEMA + EK FOLDER, POORA SUPERHERO (v3.7)

## Kul storage seema — hard cap 5 GB (default)
- Superhero ke apne data (memory, skills, gyaan-yaad, diary, logs —
  sab milakar) ki kul seema **default 5 GB** hai. Isse aage woh
  manmaani se **nahi badhega**.
- Seema **sirf Hy** badha sakta hai:
  - chat me: **"seema badhao: 10 GB"**, ya
  - app ki setting (login ke baad ki API) se.
  Superhero khud apni seema **kabhi nahi** badha sakta — program me
  uske liye koi raasta hi nahi hai.
- Seema ke **paas (90%)** aane par chetaavni, **bhar jane par woh ruk
  jata hai** aur saaf Hinglish me batata hai: "jagah bhar gayi hai —
  seema badhao ya purana hatao". **Chupchaap kuch delete nahi hota,
  chupchaap badhna bhi nahi hota.**
- App ke **"MERI JAGAH"** hisse me hamesha dikhta hai: istemal kitna /
  seema kitni, aur model ki jagah alag se.

## Ek folder — poora Superhero
- Program, memory, skills, gyaan-yaad, diary, tasks, settings — **sab
  usi ek folder ke andar** hain.
- **Model bhi isi folder me**: start wali files engine ko bol deti
  hain ki model is folder ke **models** hisse me rakhe
  (OLLAMA_MODELS yahi rakha gaya hai). Isliye Hy bas **ek folder copy
  karke** dusre laptop/folder me daale — poora Superhero, yaadon aur
  seekh ke saath, waisa ka waisa wahan chal padega.
- ⚠️ **Ek imandaar baat:** purani jagah par pehle se download model
  nayi jagah apne aap nahi aayega — **pehli baar naye folder se chalu
  karne par model ek baar (~2 GB) dobara download hoga**, phir hamesha
  folder ke andar hi rahega. (Chaaho to purana model-folder
  `%USERPROFILE%\.ollama\models` copy karke is folder ke `models`
  me daal sakte ho — dobara download nahi lagega.)
- **Bahar rehne wali ek-matra cheez:** engine ka *program* khud
  Windows me install hota hai (woh khaali chalane wala hissa hai,
  usme tumhari koi yaad/seekh nahi hoti). Naye laptop par woh ek baar
  **Dimaag-Lagao.bat** se lag jayega — uske baad folder copy karte hi
  poora Superhero tumhara hai.

## Bhavishya ka kadam (abhi nahi)
Jab paisa/computer bada hoga, Hy khud Superhero ko bade computer par
rakh kar use bada/unlimited dimaag dega. Woh vistaar bhi **sirf Hy ke
faisle aur haath se** hoga — Superhero khud kabhi apna vistaar nahi
karega.
