# Superhero — SKILLS SYSTEM (uski sabse main taakat) — v3.3

## Skills kya hain
Skill = ek **seekha hua tareeka/jaankari** (sirf text). Jaise koi khaas kaam
karne ki vidhi. Superhero ke andar ek sthaayi **Skills hissa** hai — app ki
baayein patti me "SKILLS — MERI SABSE MAIN TAAKAT" — jahan har seekhi skill
dikhti hai: **naam, kab seekhi, kitni baar istemal hui**, aur roz ki dohraai.

## Skill aati kaise hai — sirf Hy ke kehne par
Hy bas bolta hai:
- **"skill download karo: https://... (pata)"** → Superhero usi pate se text
  lekar skill bankar apne andar rakh leta hai aur seekh leta hai.
- **"skill banao: <naam> — <pura text>"** → Hy ka diya text hi skill ban jata hai.
- **Laptop ki .md/.txt file ka path** Hy khud de → wahi file skill banti hai
  (path Hy ne khud liya = uski ijaazat).
- Sirf naam bolne par Superhero **pata maangta hai** — bina pate ke woh kuch
  download nahi karta (aur nakli "seekh liya" kabhi nahi bolta).

## Seekhi skill hamesha yaad
- Skills **memory ke saath** rehti hain: `memory/skills/<naam>/SKILL.md` +
  uski jaankari (kab seekhi, kitni baar kaam aayi).
- Update system memory ko **kabhi haath nahi lagata** — isliye skill bhi
  NEVER-FORGET hai. Update aaye ya app band-bando ho, skill waisi ki waisi.

## Kaam aane par khud istemal
- Jab Hy koi kaam bolta hai, program uski seekhi skills me se **milti-julti
  skill khud dhoondh** kar Superhero ko deta hai — Hy ko sirf ek command
  deni hai, Superhero us skill ke tareeke se kaam pura karta hai.
- Har istemal gina jata hai (Skills list me "istemal: X baar").

## Roz seekhne ki aadat
- Har naye din, app khulne/baat shuru hone par Superhero **ek purani seekh
  ki dohraai** karta hai (sabse kam dohraai wali skill taza hoti hai) —
  taaki seekh majboot rahe. Ye laptop ke andar hi hota hai; iske liye
  internet **nahi** khulta.
- Dohraai Skills list me dikhti hai: *"📚 Aaj ki dohraai: ..."*

## Suraksha — pakki baatein
- Skill **sirf text** hai. **Code file (.py/.bat/.exe/.ps1...) skill bankar
  kabhi nahi aati** — program use wahin rok deta hai.
- Aayi hui skill **kabhi chalayi (execute) nahi jati** — woh sirf padhi
  jaati hai, jaise kitaab. Isiliye koi skill system me badlaav nahi kar
  sakti aur laptop ko nuksaan nahi pahuncha sakti.
- Skill ke andar likhi koi baat Superhero ke pakke taaloon (file-ijaazat,
  never-forget, delete switch) ko tod nahi sakti — taale program me hain,
  skill sirf jaankari hai.
- Badi file (200 KB se badi) skill bankar nahi aati — Superhero badi file
  swallow nahi karta, ye niyam yahan bhi hai.
