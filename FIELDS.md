# Superhero — FIELD PACKS + ROZ KI SEEKH (v3.6)

## Hy ke "skill" = bade kshetra (Fields)
- **Doctor, Engineer, Developer** — ye teen pack pehle se bane hain.
- Hy naya kshetra jod sakta hai: chat me bole — **"field jodo: <naam>"**.
- Har field ke andar **topics ka naksha** hai: buniyaad se gehraai ki
  ore kram me lage chhote topics (jaise Developer: code kya hai →
  variable → loop → function → database → API → Git...).

## Roz ka seekh-lakshya: 15–20
- Har din Superhero fields se bari-bari **15–20 naye chhote topics**
  padh kar **apne shabdon me gyaan-yaad** me rakhta hai.
- **Diary aur Field Packs hisse me ginati dikhti hai** — "Aaj ki seekh:
  X / 15–20", aur har field ki pragati (kis field me kitna seekha,
  agla topic kaun sa).
- Seekhne ka kram: Hy ke diye kshetra pehle, naksh ke kram se.

## Saaf seema (Hy ko pehle hi bata di gayi hai)
- Ek din me **poora profession ya poora GitHub store karna mumkin
  nahi** — design roz-thoda-seekhne aur gehraai badhane ka hai.
- **Pahunch, store nahi:** bada kaam aaye to Superhero pehle apni
  gyaan-yaad/skills dekhta hai, phir zaroorat par **usi samay** padhkar
  istemal karta hai.
- **GitHub/code par license ki seema lazmi** — sirf wahi istemal
  hoga jiska license ijaazat de; code ki nakal nahi.

## Internet ka taala
- Roz-seekhna **band** se shuru hota hai. Hy bole **"roz seekhna
  chalu karo"** to roz wala padhna chalu (sirf padhna, kuch bhejna
  nahi); **"roz seekhna band karo"** bolte hi band.
- Bina iske, internet sirf Hy ke seedhe aadesh (research/web-search
  ijaazat) par khulta hai — jaisa pehle tha.
- Sab kuch **Creator Suraksha Lock + permission lock** ke neeche hai.
